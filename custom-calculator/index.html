Builder tips

Make a calculator people can understand

1. Use plain names

Prefer freight_cost over cryptic names like x1.

2. Label every input

Add the unit in the label or variable unit field so users know what to enter.

3. Test edge cases

Try zero, the smallest valid value and a typical real-world value.

4. State assumptions

Freight rates, tax bases and carrier divisors may vary. Explain what your formula assumes.
