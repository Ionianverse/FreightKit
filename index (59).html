Batch Chargeable Weight

Upload a CSV with length_cm,width_cm,height_cm,qty. Optional columns: actual_kg and divisor. Dimensions are in centimetres. Set your default volumetric divisor and output precision below; a divisor supplied in a CSV row takes priority.

Required columns: length_cm, width_cm, height_cm, qty. Optional: actual_kg, divisor.

Used only when a row has no divisor.

Changes displayed/exported rounding only, not the underlying calculation.
