Privacy

Last updated: 11 October 2026. This is a draft for the current static version of FreightKit and should be reviewed before launch.

Calculator inputs and files

Most calculator calculations run in your browser. The site code does not upload calculator inputs or CSV files to a FreightKit application server. CSV tools read the selected file locally in the browser and generate results on your device.

Browser storage

The site can store saved calculator inputs and custom calculator setups in your browser's local storage. This data stays in that browser profile unless you clear it or the browser removes it. It is not a cloud backup and will not automatically follow you to another device. The saved-calculation feature may use temporary session storage to reopen saved inputs.

Hosting and technical logs

The static hosting provider may process technical information such as requests, IP addresses, browser details and error logs under its own policies. Review the hosting provider's privacy terms.

Analytics, ads and payments

The current bundle does not implement user accounts, server-side calculator storage, online payments or a dedicated analytics integration. If advertising, analytics, payment providers, accounts or other external services are added, this policy and any required consent choices must be updated before those services are enabled.

Contact

Support contact details are still being configured. A monitored contact channel must be added before public launch.

Changes

This policy may be updated when the service changes. The date above should be updated whenever a material change is made.
