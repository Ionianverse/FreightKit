Warehouse Cost per Pallet

Estimate warehouse storage cost per pallet using rent, operating expenses, capacity and occupancy assumptions.

Note: This is a simplified cost allocation. Pallets handled per month is throughput, not necessarily average occupied inventory.

Formula

Cost per position = monthly warehouse cost ÷ available positions. Estimated cost per pallet handled = monthly warehouse cost ÷ monthly pallet throughput + handling cost per pallet. This allocation assumes the entire entered warehouse cost is allocated to this throughput and is not an occupancy cost measure.
