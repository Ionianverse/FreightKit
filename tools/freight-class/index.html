Freight Class Density Guide

Estimate a density-based LTL class using current guideline bands.

Important: This is a density-only screening guide aligned to the 13-band NMFC density guideline. Actual U.S. freight class depends on the applicable NMFC item and may change with handling, stowability, liability or commodity-specific rules. Confirm the current item/class with the carrier or NMFTA ClassIT+ before shipping.

Formula

Density (lb/ft³) = shipment weight (lb) ÷ [length × width × height (in³) ÷ 1,728]. The guide uses 13 density bands; it is not an official item classification.

FAQs

Official class?

No. Density alone is not an official classification. Check the applicable NMFC item and your carrier requirements.
