Method and limits

The first version is deliberately evidence-first. It uses exact item and warehouse matches and leaves process paths without a mapped source for review.

05

Daily file matching

  • BO rows are identified by order, line, item, warehouse, and quantity.
  • Transfer pools match exact item and destination warehouse. The default eligible quantity is shipped minus received.
  • Warehouse stock uses the Available field from sheets with an Item, Whse/Branch, and Available header.
  • Shared transfer and stock quantities are consumed by BO ETA priority, so the same quantity is not allocated repeatedly.
  • When the BO workbook has an Item / Material / Per Quantity table, parent pack/kit quantities are expanded into those components.
  • Inventory process blocks can be added as ordered stages by choosing the exact pool and Stock, WIP, On Xfer, NS/QC, or GRN quantity field.
  • Planned rows with Allocate = NO can use a separate wording rule.

What stays for human review

  • Component and process mappings must match the ERP’s current material and operation rules. Rows without an exact mapping remain unassigned.
  • Transfer exports without a date cannot support a transfer ETA in generated text.
  • Existing remarks are shown beside every draft. No row is approved by default.
  • The procurement view uses a populated material pivot if available; it does not infer a three-month order quantity from an unknown forecast cadence.
